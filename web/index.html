PokeDaisy sul clamshell

Port Linux del companion dual-screen di PokeDaisy: il gioco GBA sul pannello superiore, party / borsa / mappa / lotta / guida su quello inferiore. Nessuna ROM inclusa; la demo qui sotto usa RAM di test.

schermo inferiore · companion 640×480

Sul dispositivo

  1. Compila per aarch64 (o copia il binario pokedaisy).
  2. Metti lo script in ports/PokeDaisy.sh e i file nella stessa cartella.
  3. Copia i tuoi dump .gba in roms/ (FireRed rev 1 o Emerald).
  4. Avvia da Linux Anbernic / Rocknix. Due pannelli: layout dual.

Comandi RG DS

  • D-pad / stick sinistro, A/B, Start, Select, L/R: i tasti GBA.
  • X: scheda successiva del companion. Y: indietro.
  • R2 (o Space sul PC): avanzamento rapido.
  • Tieni X+Y: salva e torna alla lista. Touch sullo schermo basso.
